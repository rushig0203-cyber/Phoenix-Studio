# Free media sources — checked November 7, 2026

More search results do not establish that a shot depicts a narrated action, a
named person or a current event. Phoenix currently uses Pexels for narrated
Create/news videos. Make a Reel additionally supports Pixabay, eligible Wikimedia
Commons and NASA videos. Archive images are not yet a scene-asset/rendering path;
adding an API name to that list would not make those images appear in a video.

| Source | Verified access and intended use | Current decision |
|---|---|---|
| [Wikimedia Commons](https://www.mediawiki.org/wiki/API:Imageinfo) | Image/video metadata, depicted subject, dates and item-specific reuse evidence. | Video adapter already connected for Make a Reel. Best first image source for cultural/historical explainers, with a separate typed still-image render path and exact subject checks. |
| [NASA Image & Video Library](https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf) | Anonymous search/asset metadata; space/science images and videos. [Media-use rules](https://www.nasa.gov/nasa-brand-center/images-and-media/) exclude assuming that every hosted asset is NASA-only or endorsement-free for all uses. | Video adapter already connected. Image extension is a candidate; third-party credits and music need item checks. |
| [Openverse](https://api.openverse.org/v1/) | Free anonymous/registered image and audio search. No current video-search endpoint. Licence filters are discovery, not independent rights verification. | Useful image-discovery candidate. A test Krishna search returned temples/processions and a different deity scene; a broad keyword alone cannot approve an illustration. Preserve exact subject, source, rights and attribution; constrain download hosts. |
| [Library of Congress](https://www.loc.gov/apis/json-and-yaml/) | Anonymous JSON search, heterogeneous item rights/resource metadata. [Rate limits](https://www.loc.gov/apis/json-and-yaml/working-within-limits/) and access blocks apply. | Historical context candidate, not current-event evidence. The live probe was blocked; do not bypass it or claim connected access. |
| [Smithsonian Open Access](https://www.si.edu/openaccess) | Free API key for production; item media must itself carry CC0 access. [API documentation](https://edan.si.edu/openaccess/apidocs/). Metadata marked CC0 does not authorize every attached image. | Cultural/history image candidate once a free owner key and eligible per-image evidence exist. No production key configured. |
| [Europeana](https://pro.europeana.eu/page/apis) | Free keys with different personal/project uses; aggregated item rights vary. | Production/project access and direct-media rights must be verified before integration. Not connected. |
| [Internet Archive](https://archive.org/developers/md-read.html) | Anonymous search and item metadata, including file sizes. [Rights](https://archivesupport.zendesk.com/hc/en-us/articles/360014759692-Rights) remain item-specific; arbitrary uploads are not automatically licensed. [Bot policy](https://archive.org/developers/bots.html) requires respectful identification/backoff. | Trusted institutional collections with explicit eligible rights only; large file sizes require bounded streaming. No arbitrary film, TV or news-rip importer. |
| [DVIDS](https://api.dvidshub.net/docs) | Registered application key, image/video search and dated/credited asset metadata. [Terms](https://api.dvidshub.net/docs/tos), [copyright exceptions](https://api.dvidshub.net/docs/copyright) and no endorsement apply. | Potential defense/humanitarian context source; key not configured. Not a general Krishna/story library. |
| [NARA / U.S. National Archives](https://www.archives.gov/research/catalog/help/api) | Requested read-only key and usage limits. Current API terms on storing returned content conflict with saving/bulk-download examples in its [official repository](https://github.com/usnationalarchives/Catalog-API). | Defer until storage/provenance use is clarified. These are the same institution, not two providers. |
| [ISRO](https://www.isro.gov.in/Copyright_Policy.html) | Official galleries and attributed-reproduction policy, with third-party exceptions. | No documented general media-search API was verified. Do not invent an “Indian NASA API.” |
| [Flickr](https://www.flickrhelp.com/hc/en-us/articles/4404070036884-Flickr-API) | New key requests are currently Pro-only. [Commercial API use](https://www.flickr.com/services/api/misc.api_keys.html) requires prior permission. | Excluded from the free-only automatic plan. |

Free website downloads and public API access are different. No new scraping,
account creation, paid subscription, API access request or credential was added
for the other stock sites supplied in chat. Coverr stays excluded as requested.

Krishna and the Butter Pot is currently one authored English/Hindi eight-beat
2D preset. Bhagavad Gita lessons, Arjuna scenes and arbitrary religious animation
are not implemented by that preset. Do not broaden its exact-topic trigger while
still substituting the butter-pot script, animal characters or unrelated temples.
Archive artwork can illustrate an explanation only when its actual subject fits;
it does not supply new character animation or verify a quoted scripture passage.
